# Qube 0.2 增强功能

## 编程协作

电脑“编程听写”默认勾选增强会话。Codex 使用本机 `codex app-server`，Claude 使用原交互终端及会话级 hooks。需要先在所选 WSL 发行版或 PowerShell 环境登录相应 CLI；Qube 不读取、保存或替换账号凭据。

Codex 的授权和提问显示为电脑端卡片；Claude 的授权和回答继续在终端完成。手机收到工作中、本轮结束、失败、等待回答或授权的事件。“本轮结束”不代表整个软件需求已经验证完成。取消增强会话可使用兼容终端，但不提供推测式完成提醒。

每个会话有独立草稿和最近 50 次编辑历史。程序重启后重新启动、选择目标会话，再从“恢复保存的草稿”中取回内容。断线后需要重新选择目标；旧请求不会自动重发。

| 指令 | 行为 |
| --- | --- |
| 进入编程听写 / 退出编程听写 | 切换输入模式 |
| 撤销刚才一句 | 删除最近口述片段，可撤销 |
| 撤销刚才的修改 / 重做 | 操作编辑历史 |
| 把最后一句删掉 | 显示删除预览 |
| 把 JavaScript 改成 TypeScript | 唯一匹配才替换，多处匹配提示手动选择 |
| 这里是 TypeScript，不是 JavaScript | 同上 |
| 把这段整理成三点 | 辅助会话产生完整草稿修改预览 |
| 确认修改 / 取消修改 | 应用或放弃修改预览 |
| 确认发送 | 检查草稿版本、目标、连接和附件后提交 |

辅助解释和翻译使用独立会话及临时工作目录，不延续编程对话。Claude 使用 `--bare` 跳过全局 hooks/技能并禁用工具；Codex 关闭 shell、补丁及 Web 搜索，采用只读沙箱并拒绝交互请求。Claude 需要支持 `--bare`、`--tools` 和 `--no-session-persistence` 等参数的版本；旧版本报错时更新 CLI，或使用基础终端听写。模型调用仍使用已有 CLI 的网络服务及额度；不新增模型账号。60 秒未完成可重试，处理中可取消。

## 截图、选中文字和剪贴板

说“截一下这个报错，帮我看看”，图片和文字先进入草稿。电脑也可点击“刷新窗口”，选择窗口后截图。图片预览、窗口名称和目标会话都需要检查后再发送。

语音开始时记录窗口；桌面按钮使用最近的外部窗口或手动选择。窗口失效时会报错，不自动改截整个屏幕。每份草稿最多 4 张图片、单张 10 MB；WSL 提交会转换图片路径，发送前校验文件摘要。图片存放在用户数据目录，脱离草稿及其撤销历史后，超过 7 天清理。

“解释这段”“翻译一下”“把这段加入草稿”优先读取所选窗口的 UI Automation 文本。不支持的应用请复制，然后使用剪贴板按钮。没有后台剪贴板监听。辅助结果不会自动发送给编程 Agent。

## 工作场景与电脑状态

在电脑“场景与记录”填写项目名称、实际路径、环境、Agent、编辑器别名和歌单。编辑器别名须先在 `applications` 中配置；参数支持 `{project}`、`{distribution}` 占位符。例如 Windows VS Code 的参数可设为 `["{project}"]`；WSL VS Code 可以配置 `["--remote", "wsl+{distribution}", "{project}"]`，并填写实际发行版名称。

- “开始写代码”：打开编辑器，复用或启动对应项目会话，播放歌单。留空歌单使用每日推荐。
- “我要休息”：尝试暂停音乐，手机开始五分钟休息。不终止 Agent。
- “开始专注”：手机开始四十五分钟专注。

场景显示各步骤状态。必需步骤失败停止后续依赖步骤；音乐失败允许其他步骤继续。“重试失败步骤”不会重复已成功的动作。配置为空时提示填写，不猜测项目路径。

“哪个程序占内存？”“显卡现在忙吗？”或“显示电脑状态”展示 CPU、内存、GPU、显存、GPU 温度和内存占用前五个进程。手机状态页打开时每两秒采样，桌面可勾选定时刷新。CPU 温度没有通用接口，显示不支持；NVIDIA 数据不可用时显示具体错误。

## 手机独立能力

灵感、提醒、计时保存在手机 Room 数据库中。电脑离线时可以手动编辑，已安排的提醒和计时继续运行；离线语音识别不在此版本中。

- “记一下：登录页需要支持扫码”：进入灵感收件箱或当前项目。支持编辑、搜索、归档、转提醒、加入任务草稿。
- “专注四十五分钟”“休息五分钟”“暂停计时”“继续计时”“结束专注”：手机独立计时。同一时间一个计时；已有计时需先结束。
- 编程听写中若要执行普通电脑/清单指令，使用“助手，记一下：……”等前缀，避免把任务正文误当控制命令。明确的草稿编辑、截图和文本辅助指令可直接使用。
- “你刚才做了什么？”：播报最近三条记录。两端按事件 ID 合并历史，显示状态及目标会话。默认保留 30 天，最多 10,000 条；历史不保存原始音频或完整截图、剪贴板正文。

## 小伙伴设置

单击眨眼，连续三次点击疑惑，长按 800 毫秒切换安静模式。动作结束恢复任务状态。待机采用随机眨眼和约 15 帧/秒动画，工作时约 30 帧/秒。

手机设置支持名称、颜色、中文离线声音、语速和音量。输入 2～6 个汉字生成新唤醒词，开启监听并试喊成功后才能确认保存。失败或取消保留旧词；未确认的试用配置不会跨应用重启生效。

普通模式播报 Agent 提示与提醒。安静/专注时只播报重要提醒和计时结束，其他事件显示通知。提醒编辑器可以勾选重要；语音可说“……重要提醒我……”。TTS 串行播放，重要提醒可中断普通播报，并尊重手机系统静音设置。
